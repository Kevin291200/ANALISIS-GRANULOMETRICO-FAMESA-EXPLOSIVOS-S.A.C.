# Informe de Fragmentación · FAMESA (versión web)
Cada visitante sube su Excel de WipFrag y genera su informe (PDF/Word). Nada se guarda: los datos viven
en la memoria de la sesión y se borran al cerrar o recargar la página.

## Publicar (Streamlit Community Cloud)
1. Crea un repositorio en GitHub y sube TODO el contenido de esta carpeta (incluida `.streamlit/`).
2. Entra a https://share.streamlit.io → Create app → "Yup, I have an app".
3. Elige repositorio, rama `main` y archivo principal `app.py`. En Advanced settings elige Python 3.12.
4. Deploy. Obtendrás un enlace `https://….streamlit.app` para compartir.
